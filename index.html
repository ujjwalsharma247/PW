Problem

Distinguish AI-generated essays from human-written text with dependable binary classification.

Approach

A 20K-word vocabulary, stop-word removal, sequence padding and a scalable tf.data pipeline.

Model

Embedding → Conv1D → 2× Bidirectional LSTM → Dense → Sigmoid, trained with Adam and binary cross-entropy.

Data

500K+ essay samples, with 97,447 held out for evaluation.

Result

99.72% test accuracy from a compact 3.63M-parameter model.

Deployment

Real-time inference through a Streamlit interface, with EarlyStopping during training.
